Feature Candidates:

- Add a "red" stylemode

- Selectable activity type in activity header: Add a dropdown to the activity header with all the activity types.  Selecting one despawns the current activity and spawns a new window of the selected type with the same size and position.

- Add a "respawn" button to the activity header.  Clicking replaces the current activity window (in the same way as the dropdown) with a different, randomly chosen activity in the same window size and position.

- Make the default layout three activities wide by two high.

- Add a "Graph" activity type which shows a line chart of a variable like stock price, temperature, or population over time

- Add an "Orbital View" activity type which shows a 3d svg view of the earth with 1-30 satellite orbits superimposed.  The satellites update position in real time.  Display a mix of LEO, Mid, and Geosynchronous orbits with random inclinations and argument of perigee.

- Make the activity windows resizable

- Add the ability to specify the layout (number of activities wide x high) for the base grid.  Could be a dropdown with a fixed list of options, could be edit fields for width and height.  Make a suggestion.
