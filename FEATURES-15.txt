FEATURE 1: ?obs=1 Transparent Background Mode
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Effort: XS (1 CSS rule + 1 URL param)

PURPOSE
  Unlocks BizzBox as an OBS Browser Source. OBS composites transparent areas
  with the layer below, so setting background to transparent makes BizzBox a
  live overlay on top of a camera feed, game capture, or other scene.

CURRENT STATE

    ?kiosk, ?viewer, ?lock — same pattern.
  - Backgrounds come from CSS vars: --color-bg on html/body (layout.css:15),
    .background-grid (layout.css:53), .bg-slot--empty (layout.css:66).
  - CRT scanline overlay: body::after (layout.css:23-36).
  - Boot screen uses var(--color-bg) (index.html:22).

IMPLEMENTATION

  1. store.js — add ?obs=1 param (1 line)
     In parseUrlOverrides(), add:
       if (params.has('obs')) o.obs = params.get('obs') === '1';

  2. app.js — apply class on mount (2 lines)
     In the setup function, after kiosk/viewer mode checks:
       if (urlOverrides.obs) document.documentElement.classList.add('obs-mode');

  3. layout.css — add .obs-mode rules (~8 lines)
       html.obs-mode,
       html.obs-mode body {
         background: transparent !important;
       }
       html.obs-mode .background-grid {
         background: transparent;
       }
       html.obs-mode .bg-slot--empty {
         background: transparent;
       }
       html.obs-mode body::after {
         display: none;                /* kill scanline overlay */
       }
       html.obs-mode .boot-screen {
         background: transparent;
       }

  4. (Optional) Hide header in OBS mode by default — streamers won't need
     controls. Consider auto-applying lock mode:
       if (urlOverrides.obs) { urlOverrides.lock = true; }

USAGE
  OBS → Sources → Browser → URL:
    https://bizzbox-lkbxm.ondigitalocean.app/?obs=1&scene=War%20Room&lock=1

TESTING
  - Open ?obs=1 in Chrome: background should show as white (browser's default
    for transparent). Confirm no scanlines, no dark bg behind grid gaps.
  - Activity content (tiles, windows) should render normally.
  - In OBS, verify chroma-key-free transparency works.

FEATURE 2: Scene-Specific Vanity URLs
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Effort: S (Flask route + slug lookup)

PURPOSE
  "bizzbox.app/war-room" is far more shareable than "?scene=War%20Room".
  Improves SEO for scene names and looks professional in social shares.

CURRENT STATE
  - Single Flask route: @app.route("/") → render_template("index.html")
    (app.py:36-38).
  - 27 built-in scenes defined in scenes.js:10-39 with name field.
  - ?scene=Name already works — socket.js applies it on sync:init.
  - Custom scenes live in localStorage (not shareable server-side).

DESIGN DECISION: Server redirect vs. client routing
  Recommend server-side catch-all that redirects to /?scene=<name>.
  Keeps the SPA architecture intact — no client-side router needed.

FEATURE 3: Screenshot Export Button
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PURPOSE
  One-click capture of the current display state — share on social media,
  embed in docs, or archive a moment.

CURRENT STATE

  - Activities render via HTML/CSS (DOM elements, not <canvas>).
  - Foreground windows are absolutely-positioned divs.
  - Header auto-hides; needs to be hidden during capture.

APPROACH: html2canvas
  html2canvas renders the DOM to a <canvas>, then exports as PNG.
  It's the de-facto standard for client-side screenshots. ~40KB gzipped.
  Alternative: native browser APIs (not available cross-browser for full-page).

IMPLEMENTATION

  1. Add html2canvas library
     Option A (CDN, simplest):
       <script src="https://cdn.jsdelivr.net/npm/html2canvas@1.4.1/dist/html2canvas.min.js"></script>
     Option B (local copy, like socket.io and Vue):
       Download to static/js/html2canvas.min.js, add <script> to index.html.
     Recommend Option B for consistency with existing local-vendor approach.

  2. AppHeader.js — add screenshot button to Row 3 utility group
     Between FULLSCR and PIN buttons (AppHeader.js:503-510):

  3. AppHeader.js — add takeScreenshot function in setup():

       async function takeScreenshot() {
         // Temporarily hide header so it's not in the screenshot
         const header = document.querySelector('.page-header');
         if (header) header.style.display = 'none';

         try {
           const canvas = await html2canvas(document.body, {
             backgroundColor: null,     // preserve transparent if OBS mode
             scale: window.devicePixelRatio || 1,
             useCORS: true,
             logging: false,
           });

           // Trigger download
           const link = document.createElement('a');
           link.download = `bizzbox-${Date.now()}.png`;
           link.href = canvas.toDataURL('image/png');
           link.click();
         } finally {
           if (header) header.style.display = '';
         }
       }

       import { store } from './store.js';
       import { ACTIVITY_TYPES } from './activityTypes.js';
       import { encodeSceneToBase64 } from './scenes.js';

       /**
        * Build a full shareable URL from current app state.
        * Uses individual params (not scene_data) for readability.
        */
       export function buildConfigUrl() {
         const params = new URLSearchParams();
         params.set('style', store.config.style);
         params.set('layout', `${store.grid.cols}x${store.grid.rows}`);
         params.set('intensity', store.config.intensity);
         params.set('windows', store.config.fgTarget);
         if (store.config.muted) params.set('muted', '1');

         // Activity filter: only include if not "all enabled"
         const allEnabled = ACTIVITY_TYPES.every(t => store.activityFilter[t]);
         if (!allEnabled) {
           // Encode as scene_data to keep URL shorter
           const scene = {
             name: 'Shared',
             style: store.config.style,
             cols: store.grid.cols,
             rows: store.grid.rows,
             intensity: store.config.intensity,
             fgTarget: store.config.fgTarget,
             ambientPreset: store.ambientPreset || null,
             filter: ACTIVITY_TYPES.filter(t => store.activityFilter[t]),
           };
           // Switch to scene_data encoding when filter is active
           return `${origin}/?scene_data=${encodeSceneToBase64(scene)}`;
         }

         if (store.ambientPreset) {
           // Ambient can't be set via basic params — use scene_data
           const scene = {
             name: 'Shared',
             style: store.config.style,
             cols: store.grid.cols,
             rows: store.grid.rows,
             intensity: store.config.intensity,
             fgTarget: store.config.fgTarget,
             ambientPreset: store.ambientPreset,
             filter: null,
           };
           return `${origin}/?scene_data=${encodeSceneToBase64(scene)}`;
         }

         return `${origin}/?${params}`;
       }

       export function copyConfigUrl() {
         const url = buildConfigUrl();
         return navigator.clipboard.writeText(url).then(() => url);
       }

           document.addEventListener('click', hide);
         });
         onUnmounted(() => {
           document.removeEventListener('contextmenu', onContextMenu);
           document.removeEventListener('click', hide);
         });

         return { visible, x, y, copyLink };
       }
