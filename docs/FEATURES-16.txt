1. Volume Control in Header
---------------------------

### Current State

Audio is binary: MUTED (gain 0) or SOUND (master gain hardcoded at 0.4).
The AudioEngine in audio.js controls:
  - masterGain: single GainNode gating all output (0.4 or 0)
  - ambientGain: per-preset gain that scales with intensity
  - event sounds: playSpawn, playDespawn, playActivitySound, etc.

All audio flows through masterGain, so a single volume knob controls everything.

### Design

Add a range slider next to the MUTED/SOUND button in Row 3. The slider
controls master volume (0-100%, stored as 0.0-1.0 internally). Mute sets
gain to 0 without moving the slider; unmute restores the slider value.

URL parameter: `vol=0`..`100` (integer percentage). Example: `?vol=30`
maps to internal gain 0.3 * 0.4 = 0.12. The 0.4 base gain stays as the
ceiling; vol scales within it. vol=100 means 0.4 gain (current max).

If `muted=1` is also set, the slider position is preserved but gain is 0.

### URL Parameter

  `vol=N` where N is 0-100 (integer percentage)

  - `vol=0` is equivalent to `muted=1` (gain = 0)
  - `vol=100` is full volume (gain = 0.4, the existing max)
  - `vol=50` is half volume (gain = 0.2)
  - Omitting `vol` defaults to 100 (or saved preference)
  - If both `vol` and `muted=1` are present, muted wins (gain=0),
    but slider position reflects vol value for when user unmutes

### Interaction with Mute

  - Clicking MUTED/SOUND toggles mute. Muting sets gain to 0 but
    preserves the slider position. Unmuting restores gain to slider value.
  - Dragging slider to 0 auto-mutes. Dragging above 0 auto-unmutes.
  - The MUTED/SOUND button label reflects the mute state, not the
    slider position.

2. README-OBS.md — OBS Setup Guide
-----------------------------------

### Purpose

A standalone guide for OBS Studio users who want to use BizzBox as a
browser source overlay or background. Covers setup, recommended settings,
and common configurations.

### Content Outline

  1. Quick Start
     - Add Browser Source in OBS
     - Set URL to BizzBox instance (local or hosted)
     - Recommended dimensions (1920x1080 or match canvas)
     - Check "Shutdown source when not visible"

  2. Transparent Background Mode
     - Use `?obs=1` parameter
     - Explains what it does: transparent bg, no header, no scanlines
     - Combined with scenes: `?obs=1&scene=War+Room`
     - Note: OBS browser source must have transparent bg enabled

  3. Recommended URL Configurations
     - Full-screen background: `?scene=Ambient&lock=1`
     - Overlay with transparency: `?obs=1&scene=Hacker+Den`
     - Specific activity only: `?obs=1&layout=1x1&windows=0`
     - Muted (if using own audio): `?obs=1&muted=1`
     - With volume control: `?obs=1&vol=30`
     - Kiosk mode: `?kiosk=1&scene=War+Room`

  4. Performance Tips
     - Lower intensity for less CPU: `&intensity=3`
     - Fewer windows: `&windows=0`
     - Smaller grid: `&layout=3x2`
     - "Shutdown source when not visible" in OBS
     - Hardware acceleration in OBS browser source settings

  5. Embed Code
     - Mention the Embed Code generator in the header
     - Show example OBS-ready URL from embed modal

  6. Vanity URLs
     - Scene shortcuts: `/war-room`, `/hacker-den`, etc.
     - Can combine with params: `/war-room?obs=1&vol=50`

  7. Troubleshooting
     - Black screen: check URL, check server running
     - White background instead of transparent: add `?obs=1`
     - Audio: OBS browser sources can play audio; use vol param
     - Lag: reduce intensity and window count
     - Reconnecting: OBS browser source may need refresh
